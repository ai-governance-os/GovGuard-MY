# Evidence Pack Note

Route A is a real-case-derived workflow based on a school charity bazaar
administrative process. To protect privacy, this submission uses synthetic
stakeholder and donor data throughout.

The real event structure is used **with the school's signed acknowledgement**.
Because acknowledgement for competition evaluation does not automatically mean
permission for permanent public-source attribution, this public repository
replaces the school name with the generic label **Johor SJK(C) Primary School**.
The supporting evidence (signed acknowledgement letter, signed redacted meeting
record, public event poster, and public Facebook post) remains in the private
competition evidence materials and is not included in this repository.

This repository intentionally does not include real donor lists, private
WhatsApp screenshots, parent contact details, student-sensitive records, or
real person-level contribution histories.

The purpose of Route A is to demonstrate governed administrative procedure,
not to expose private school-community records.
